# Seed photos

Drop 12–15 JPEGs here before running `pnpm seed`. The script skips photo
seeding if this directory is empty, so the rest of the dataset still loads.

**Requirements**

- Real photographs, not placeholders or solid colours — an evaluator notices
- Mixed portrait and landscape so the masonry grid shows varied aspect ratios
- Resize to ~1600px on the long edge; 5 MB originals do not belong in git
- **No identifiable real children.** Prefer activity or scene shots, or clearly
  stock imagery. This is a child-privacy product; using real children's photos
  as demo data would undercut the entire premise.

Unsplash and Pexels both permit this use. Record what you used in `CREDITS.md`
alongside the images.
